Algorithm Overview (Updated)

1
Dust Filter 
best_ask_raw = lowest ask WHERE quantity >= min_executable_qty_for_reference
best_bid_raw = highest bid WHERE quantity >= min_executable_qty_for_reference
2
Reference Validity Constraint NEW 
IF both sides exist:
    spread = best_ask_raw - best_bid_raw
    IF spread > max_reference_spread:
        REJECT snapshot → all metrics = NULL
ELSE:
    REJECT snapshot → all metrics = NULL
3
Reference Price (only if valid) 
reference_price = (best_ask_raw + best_bid_raw) / 2
4
Band Filter 
best_ask = lowest ask WHERE price IN [reference_price - delta, reference_price + delta]
best_bid = highest bid WHERE price IN [reference_price - delta, reference_price + delta]

Remaining Minor Considerations

1. Delta vs Spread Relationship

When max_reference_spread = 0.20 but delta = 0.01, a book with spread = 0.15 will:

  • Pass the reference validity check (0.15 ≤ 0.20) ✓
  • But have NULL best prices (band too narrow) ⚠️

Recommendation: Consider constraint: delta >= max_reference_spread / 2 or document this as expected behavior.

2. Phase-2 Considerations (Documented)

The PRD correctly identifies these for future phases:

  • Dynamic delta (spread/volatility based)
  • Per-exchange or per-market deltas
  • Controlled one-sided reference fallback
  • Liquidity quality scoring
